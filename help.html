Help & Support - FarmerCart

How To Order?

1. Select product → Add To Cart
2. Go to Cart → Place Order
3. Fill address → Place Order
4. Track in My Orders

Payment Options

COD, UPI, Card - All available. COD is most popular.

Delivery Time

2-3 days for Seeds, Fertilizer, Pesticides. Same day / Next day for Fresh Crops. Free delivery above ₹499.

Return Policy

If product is damaged or wrong, you will get replacement or refund within 7 days.

How FarmerCart Works - Like Flipkart

Step 1: Browse

Select category - Seeds, Fertilizer, Pesticides, Fresh Crops, Grocery.

Step 2: Add To Cart

Click ADD TO CART (Yellow) or BUY NOW (Green).

Step 3: Checkout

Fill address, select COD / UPI / Card, Place Order.

Step 4: Track

Go to My Orders, track Ordered → Packed → Shipped → Delivered.

Step 5: Seller Dashboard

Owner login with owner@farmercart.com, add products, update order status.
